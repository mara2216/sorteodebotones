# Elige tu destino 🎲

Una aplicación web moderna, limpia y minimalista creada con **HTML5, CSS3 y JavaScript Vanilla**.

## 🚀 Características
- **Título principal**: "Elige tu destino" con diseño centrado y elegante.
- **Dos botones interactivos**: Botón Amarillo y Botón Azul con degradados vibrantes, sombras difuminadas y micro-animaciones al pasar el cursor o hacer clic.
- **Resultado aleatorio**: Al presionar cualquiera de los dos botones, se revela instantáneamente un mensaje aleatorio:
  - 🏆 **"Has ganado"** (con animación de pulso verde y confeti).
  - ❌ **"Has perdido"** (con efecto de vibración sutil).
- **Botón "Volver a jugar"**: Permite reiniciar la partida y volver a probar suerte inmediatamente.
- **Estadísticas en vivo**: Contador de victorias, derrotas y total de partidas jugadas.
- **Efectos de sonido sintetizados**: Audio nativo mediante Web Audio API (sin descargas externas).
- **Atajos de teclado**: Presiona la tecla `R` para volver a jugar una vez terminada la ronda.
- **Diseño completamente responsivo**: Adaptado para computadoras de escritorio, tablets y dispositivos móviles.

## 📁 Estructura del proyecto
```
sorteodebotones/
├── index.html   # Estructura semántica y accesible
├── style.css    # Estilos modernos con glassmorphism y animaciones
├── app.js       # Lógica del juego, azar, efectos de sonido y confeti
└── README.md    # Documentación del proyecto
```

## 💻 Cómo ejecutar
No se requiere instalación ni servidor backend. Puedes abrir directamente el archivo `index.html` en cualquier navegador web moderno:
- Haz doble clic en `index.html`, o
- Arrástralo a la ventana de tu navegador favorito (Chrome, Safari, Firefox, Edge).
